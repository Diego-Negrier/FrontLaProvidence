## 🚀 WORKFLOW RAPIDE

### Étape 1: Télécharger (5 min)

**Pour Sketchfab** (Recommandé):
```
1. Aller sur: https://sketchfab.com/search?q=medieval+house&type=models&features=downloadable
2. Cliquer sur un modèle low-poly
3. Download 3D Model → Auto-detect (glTF)
4. Dézipper
```

**Pour Poly Pizza** (Le Plus Rapide):
```
1. Aller sur: https://poly.pizza/?s=house
2. Cliquer sur un modèle
3. Download GLB → Direct!
```

### Étape 2: Placer dans le Projet (1 min)

```bash
# Copier le fichier .glb vers:
cp ~/Downloads/model.glb /Users/diego-negrier/SynologyDrive/APPLICATION_PROJET/ProjetLaProvidence/FrontLaProvidence/public/models/buildings/
```

### Étape 3: Utiliser (2 min)

**Option A: Utiliser MaisonBlender.tsx existant**

Dans `Scene3D.tsx`:
```typescript
import { MaisonBlender } from './Buildings/MaisonBlender';

// Modifier le chemin dans MaisonBlender.tsx:
useGLTF('/models/buildings/medieval_house_downloaded.glb')

// Ajouter plusieurs fois:
<MaisonBlender position={[5, 8, 10]} scale={2} />
<MaisonBlender position={[10, 8, 5]} scale={1.5} />
<MaisonBlender position={[-5, 8, 8]} scale={2.2} />
```

**Option B: Créer composant spécifique**

Créer `Village3D/Buildings/EgliseTelechargee.tsx`:
```typescript
import { useGLTF } from '@react-three/drei';

export function EgliseTelechargee({ position = [0, 8, 0] }) {
  const { scene } = useGLTF('/models/buildings/church.glb');
  return <primitive object={scene.clone()} position={position} scale={3} />;
}

useGLTF.preload('/models/buildings/church.glb');
```

## 💡 ASTUCES

### Choisir le Bon Modèle:

✅ **BON**:
- Low-poly (< 50k triangles)
- Format GLB ou GLTF
- Textures incluses
- Style cohérent avec votre village
- Preview 3D disponible

❌ **ÉVITER**:
- High-poly (> 100k triangles)
- Formats propriétaires (.max, .c4d)
- Sans textures
- Trop réaliste (pas de cohérence)

### Optimiser les Modèles Téléchargés:

Si le modèle est trop lourd:

1. **Ouvrir dans Blender**
2. **Add Modifier → Decimate**
3. **Ratio: 0.5** (réduit de 50%)
4. **Apply**
5. **Export GLB**
